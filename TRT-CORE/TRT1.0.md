時間還原理論（TRT）
Time Restoration Theory
作者：Σ-Ω
DOI:10.5281/zenodo.22161713
核心總綱
時間還原理論（Time Restoration Theory, TRT）的核心目的，是重新確定：
生成結構是否必須以時間作為其最底層條件。
TRT 不取消時間，也不否定時間作為測量、標記、排列與描述工具的功能。
TRT 所檢的是：若不先把時間放入生成結構，生成本身是否仍可成立、形成差異、保持結構關係並
持續生成。
TRT 從生成結構自身出發，將生成現象拆解為三個不可互相取代的基本生成面向：
Sᵢ → Sᵢ₊₁ 位置生成
Sⱼ = Sᵢ 結構同型
Cᵢ → Cᵢ₊₁ ∨ Cᵢ → ∅ 延續／中止
三者不是三個先後步驟，也不是三個彼此獨立的實體，而是同一生成結構中的三個基本生成面向。
結構 → 關係 → 生成 → 差異 → 表示
生成 → 差異 → 時間表示
TRT 使用文字、符號與公式描述生成結構，但文字、符號與公式仍然只是表示。
表示可以精確，但表示不因此成為結構本身。
表示使不同屬性共同包含於同一表示狀態，而不使其成為同一；這種共同成立而不互相取代的關係形
成張力。
TRT 移除的是「時間作為底層生成條件」的預設，不是移除表示本身。
以下十四章沿同一問題鏈展開。每一章處理前一章自然產生的下一個問題，最後重新回到第一章的核
心問題。
第一章 核心問題：生成是否必須以時間為底層條件？
TRT 的第一個問題只有一個：
生成結構是否必須以時間作為最底層條件？所謂「底層條件」，是指：如果移除該條件，生成結構是否仍能成立。
如果生成、差異、延續及結構關係都必須先依賴時間才能成立，那麼時間就具有底層生成地位。
反之，如果這些關係可以先由生成結構自身成立，而時間只在之後對已成立的差異提供測量、標記與
描述，那麼時間就不必位於生成結構的最底層。
因此，TRT 不先假設：
Sᵢ → Tᵢⱼ → Sⱼ
而是先問：
如果不放入 T，生成關係本身還能不能成立？
然而，在回答這個問題以前，必須先處理另一個更基本的問題：
我們用來描述生成結構的模型、圖形、符號與時間標記，是否就是生成結構本身？
這導向第二章。
第二章 結構與表示：表示是否等於結構？
生成結構可以經由表示形成模型：
結構 ──表示──→ 模型
但：
模型 ≠ 結構
表示是結構與模型之間成立的關係；模型是生成結構的表示狀態。「≠」表示關係兩端仍保有各自成
立的屬性。表示使這些屬性共同包含於同一表示狀態，而不使其成為同一；因此，表示本身就是各自
屬性共同成立所形成的張力。
不同屬性可以共同成立，但不因此互相取代；差異不需要由表示額外製造，而是在各自屬性共同成立
的關係中自然存在。
例如：
S₀ → S₁ → S₂ → S₃
可以在紙面上由左向右排列。
但「向右」屬於表示形式，不代表生成結構本身具有物理上的右方。
表示方向 ≠ 生成方向的物理空間性
同樣地：
A → B → C → D → A
可以畫成圓形。
圓形表示 ≠ 週期結構本身圓只是表示週期關係的一種模型方式。
時間也是如此。如果模型使用秒、分鐘、日期、時間軸或時間座標來表示生成差異，只能說明時間存
在於模型的表示方式中，不能直接推出生成結構本身必須依賴時間才能成立。
時間表示 ≠ 生成結構
這個區分同樣適用於 TRT 自己。TRT 使用 S、C、G、Δ、箭頭與其他符號，但這些符號只是對生成
關係的表示。
公式 ≠ 結構
文字 ≠ 結構
模型 ≠ 結構
表示可以非常精確，但精確不等於本體同一。
因此，當表示與結構分離後，真正的問題便可以被提出：
如果不先加入時間表示，生成關係本身是否仍然成立？
第三章 關係與位置生成：沒有時間，生成能否成立？
TRT 的第一個基本生成面向為：
Sᵢ → Sᵢ₊₁
它表示位置生成。箭頭表示生成關係的指向，不表示：
• 物理位移；
• 空間方向；
• 時間流動；
• 已經預設的一段時間經過。
因此它不是：
Sᵢ → 時間經過 → Sᵢ₊₁
而是：
Sᵢ → Sᵢ₊₁
生成位置進入生成關係，生成位置由該生成關係形成。
只要生成關係繼續成立：
Sᵢ → Sᵢ₊₁ → Sᵢ₊₂ → ⋯
生成位置即可繼續形成。
這裡並不需要先回答「經過多久」。TRT 此處所確定的，只是生成位置之間存在生成關係。
因此，在移除時間作為底層條件後，位置生成仍然可以被描述。但生成位置形成，就自然產生下一個問題：
生成位置與指定生成位置之間，是否已經具有差異？
第四章 生成與差異：差異是否需要時間建立？
不同生成位置之間可以直接具有差異：
Δ(Sᵢ,Sⱼ)
Δ 表示在指定判定面向上的差異。
• 生成位置差異；
• 結構差異；
• 關係差異；
• 狀態差異。
當：
Sᵢ → Sᵢ₊₁
成立時，Sᵢ₊₁ 是生成位置。
因此：
Δ(Sᵢ,Sᵢ₊₁)
隨生成位置形成而自然成立。
這個差異不是外加條件，也不是由時間或表示製造。生成位置形成，它與指定生成位置不屬同一位置，
因此生成位置差異隨之自然成立。
這與第二章的張力一致：不同位置或不同屬性可以共同進入同一關係，但不因此成為同一；差異由關
係本身展開，而不是由表示反向創造。
生成 → 生成位置 → 差異
而不是：
時間 → 差異 → 生成
因此，時間不是生成位置差異成立的必要前提。
然而，這立刻產生另一個問題：
如果所形成的生成位置，具有與指定生成位置完全相同的結構，那麼生成位置差異會不會消失？
這導向第二個基本生成面向。
第五章 結構同型：相同是否等於返回？TRT 的第二個基本生成面向為：
Sⱼ = Sᵢ
它表示結構同型。這裡的等號必須依指定判定面向理解。
不同生成位置可以在指定結構判定維度上具有同型結構。
例如：
A₀ → B₀ → C₀ → A₁
可以同時成立：
A₁ = A₀ （結構判定）
A₁ ≠ A₀ （生成位置判定）
結構同型 ≠ 生成位置同一
所以：
Δ(A₁,A₀)
仍然自然成立。
結構可以重現，生成位置不因此返回。
「再次出現相同結構」不能直接被判定為「回到原生成位置」。因此，TRT 把「結構是什麼」與
「它在哪一個生成位置成立」分開判定。
但如果生成過程中有些結構可以重現，另一些結構也可能不再延續。
某個指定結構中止，是否等於整個生成中止？
第六章 延續與中止：局部結束是否等於整體結束？
TRT 的第三個基本生成面向為：
Cᵢ → Cᵢ₊₁ ∨ Cᵢ → ∅
它表示延續／中止。
其中：
Cᵢ → Cᵢ₊₁
表示指定結構的延續關係成立。
而：
Cᵢ → ∅
表示該指定結構的延續關係中止。
但 ∅ 不表示整個生成結構消失。
指定結構中止 ≠ 生成結構中止以下兩個關係可以同時成立：
Cᵢ → ∅
Sᵢ → Sᵢ₊₁
也就是說，某個指定結構可以不再承接，但生成位置仍然形成。因此，生成結構不需要因為某個局部
結構停止而整體停止。
至此，TRT 的三個基本生成面向已經完整形成：
Sᵢ → Sᵢ₊₁ 位置生成
Sⱼ = Sᵢ 結構同型
Cᵢ → Cᵢ₊₁ ∨ Cᵢ → ∅ 延續／中止
三者不是三次生成，也不是三個獨立實體，而是同一生成結構中不可互相取代的三個基本生成面向。
如果一個結構中止、另一個結構延續，而某個既有結構又重新出現，我們是否應該把這種現象理解為
返回？
第七章 週期與重現：再次出現是否代表倒轉？
考察週期關係：
A → B → C → D → A
如果只看結構名稱，它看起來像是回到 A。
但如果加入生成位置判定：
A₀ → B₀ → C₀ → D₀ → A₁
則可以同時成立：
A₁ = A₀ （結構同型）
A₁ ≠ A₀ （生成位置不同）
週期重現 ≠ 生成位置返回
這裡第一次把前三個基本生成面向放入同一結構壓力測試。位置生成使 A₁ 成為生成位置；結構同型
使 A₁ 可以具有與 A₀ 相同的結構；延續／中止則允許週期內不同指定結構承接、中止或重新成立。
所以週期不需要被理解為生成方向倒轉。圓形也只是週期關係的一種表示。
結構可以重現，而生成位置不回返。
到這裡，位置生成、差異、結構重現與局部延續都可以在沒有預設時間的情況下成立。
時間究竟在這些已經成立的生成差異上做了什麼？第八章 差異與時間表示：時間究竟做了什麼？
當：
Δ(Sᵢ,Sⱼ)
已經成立時，可以進一步對這個差異提供時間表示：
Δ(Sᵢ,Sⱼ) → Tᵢⱼ
• Δ(Sᵢ,Sⱼ) 是生成結構中已成立的差異；
• Tᵢⱼ 是對該差異提供的時間表示。
差異 → 時間表示
生成 → 差異 → 時間表示
時間可以對生成差異進行：
• 測量；
• 標記；
• 排列；
• 比較；
• 描述。
但不能因為時間可以測量差異，就反向推出時間產生了差異。同樣地，也不能因為時間可以標記兩個
生成位置，就反向推出時間產生了生成位置。
時間具有表示功能，不等於時間具有底層生成地位。
「生成 → 差異 → 時間表示」判定的是時間進入關係的位置，不表示生成在表示層終止。差異成立
後可以形成表示；表示一旦形成，形成表示狀態，並可進入後續生成。生成位置形成，生成位置差異
自然成立。
生成 → 差異 → 表示 → 生成位置 → 差異 → 表示 → ⋯
因此，表示不是生成的終點；時間只是表示的一種。時間表示可以進入後續生成，但不因此成為生成
的底層原因。
這完成了 TRT 第一階段的判定。
然而，生成結構不只存在單一路徑。如果位置生成、結構同型以及其他既有關係可以共同成立，便產
生下一個問題：
不同生成面向能否共同成立於同一生成位置？
第九章 共同生成位置 G：不同面向如何共同成立？在同一生成結構中，不同基本生成面向可以共同作用於同一生成位置。TRT 將這個共同生成位置表
示為：
Sᵢ → G ← Sⱼ
G 是同一生成結構中，不同基本生成面向及其差異關係共同成立的生成位置。
這不是兩個彼此獨立的實體從外部會聚到一個點，也不是兩條互不相關的生成路徑偶然相遇。Sᵢ 與
Sⱼ 可以表示同一生成結構中不同關係面向的既有生成位置；它們共同作用於同一生成位置 G。
• G 不是第四個基本生成面向。
• G 不是獨立於生成結構之外的實體。
• G 不是時間點。
• G 也不是幾何空間中的交會點。
「G」只是模型中對共同生成位置的表示。
符號 G ≠ G 所表示的生成關係本身
如果 G 與某個既有位置 S₀ 在指定結構維度同型，則可以同時成立：
G = S₀ （結構判定）
G ≠ S₀ （生成位置判定）
因此：
Δ(G,S₀)
仍然成立。
不同生成面向可以在 G 共同成立。G 形成為生成位置，其與既有生成位置之間的差異即自然成立。
G 所處理的不是消除或保存差異，而是同一生成結構中不同面向與不同差異之間如何形成關係。
如果 G 是共同形成的目標位置，到達 G 是否代表生成結束？
第十章 目標與起點：共同位置是否就是終點？
考察：
Sᵢ → G
G 可以是某一生成關係的目標。
目標 ≠ 終止條件
因此：
Sᵢ → G
不能推出：
G → ∅相反地：
Sᵢ → G → Sₖ
完全可以成立。
G 可以是前一生成關係的目標，同時成為下一生成關係的起點。
這不是同一位置倒退，也不是生成方向反轉。G 作為生成位置，可以承接下一個生成關係。
當：
G → Sₖ
成立時：
Δ(G,Sₖ)
也隨之自然成立。
生成位置 → 差異 → 目標 → 起點 → 生成位置 → 差異
整套關係仍然不要求時間先進入底層。
G 因而不是一個封閉終點。它是生成關係中的共同位置，同時可以成為後續生成的承接位置。
把局部成立的 G 放回整體生成鏈後，它與原有生成位置的關係如何判定？
第十一章 局部與整體：G 如何重新進入整體生成？
把 G 放回同一生成結構：
S₀ → ⋯ → Sᵢ → G → Sₖ → ⋯
G 在局部關係中是共同生成位置。但當它重新進入整體生成鏈時，原先建立的所有判定仍然有效。
如果：
G = S₀
在指定結構維度成立，仍然可以同時有：
G ≠ S₀
生成位置不同，以及：
Δ(G,S₀)
生成位置差異。
同時：
Sᵢ → G → Sₖ
表示 G 的目標—起點承接關係。
因此，在同一整體結構中，可以共同成立：• 結構同型；
• 生成位置不同；
• 生成位置差異；
• 目標—起點承接；
• 後續生成。
這些不同判定面向不需要彼此合併成同一判定。
局部成立不切斷整體。
局部關係可以重新放回同一生成鏈中判定。
不同判定可以共同成立，並形成彼此的關係，而不需要被合併為同一。
但如果多個判定同時成立，接下來就需要一個問題：
如何在整體層級對這些已成立的關係進行總和表示？
第十二章 整體判定：高階總和關係表示什麼？
TRT 使用：
G ≃ S₀
作為高階總和表示。≃ 不是單純的相等符號。它不是第四個基本生成面向，也不是另一生成規則。
它只是在整體判定層級，對前面已經成立的多項關係進行共同表示。其至少承接：
G = S₀ 結構同型
G ≠ S₀ 生成位置不同
Δ(G,S₀) 生成位置差異
Sᵢ → G → Sₖ 目標—起點承接
因此：
G ≃ S₀
不能被解讀成 G 與 S₀ 在所有判定面向完全同一，更不能被解讀為 G 回到 S₀。
高階總和表示 ≠ 本體同一
≃ 的作用，是在整體層級共同表示已成立的不同判定及其相互關係，而不以其中一項判定取代另一項。
差異不需要由 ≃ 特別保存；生成位置形成時，差異已隨之自然成立。
這與第二章完全一致：
表示可以承接多項結構關係，但表示本身不因此成為結構。
至此，另一個問題必然出現。如果 TRT 認為模型、符號與高階總和都只是表示，那麼 TRT 自己的文字、公式與後續解讀，是不是
也必須接受同樣的限制？
第十三章 理論自身的表示：TRT 是否也受自己的規則限制？
答案是：
是。
TRT 不能把「表示 ≠ 結構」只用來判斷外部模型，卻不作用於自己。
TRT 的文字本身也是表示。TRT 的公式也是表示。TRT 的圖形也是表示。任何閱讀、摘要、翻譯、
分類、重新編排或 AI 解讀，也都是表示。
文本 A ≠ 對文本 A 的後續表示
即使後續文本精確重現原文本，也可以同時成立：
文本 B = 文本 A （結構判定）
文本 B ≠ 文本 A （生成位置判定）
因此：
Δ(文本 A,文本 B)
仍然可以成立。
這不表示文本 B 一定錯誤。它只是表示：
精確重現 ≠ 返回原生成位置
同樣地，一個詞彙的意義不能只靠日常語義固定。它必須依所在關係與指定判定面向理解。
例如「差異」可能是：
• 結構差異；
• 生成位置差異；
• 狀態差異；
• 關係差異。
「表示」也可能承接：
• 描述；
• 測量；
• 標記；
• 命名；
• 分類；
• 符號化。詞彙 → 關係 → 判定 → 整體
不得用常用詞義取代本文定義。不得用局部判定取代整體關係。不得用後續表示反向改寫其生成來源。
文本 A 與文本 B 可以共同進入後續生成：
文本 A → 後續表示
文本 B → 後續表示
而後續表示仍然可以形成表示。
表示不是生成的終點。表示一旦形成，即形成表示狀態，並可作為生成位置進入後續關係；生成位置
形成後，差異自然成立，而差異又可以形成表示。
差異 → 表示 → 生成位置 → 差異 → 表示 → ⋯
表示可以承接結構，但表示不能取代結構。
這使 TRT 對自己的限制與其第二章完全一致。也因此，TRT 不需要追求一個「沒有表示的理論」。
這在語言層面並不可能。
TRT 真正要求的是：移除時間作為底層生成條件的預設，並使用不預設時間的關係表示來描述生成
結構。
一旦這一點成立，便可以進入最後一個結構問題：
前三個基本生成面向以及其展開的共同、承接與整體關係，如何回到 TRT 對時間位置的核心判定？
第十四章 時間的位置：回到第一個問題
第一章提出：
生成結構是否必須以時間作為最底層條件？
現在重新檢整條推導。
首先，表示與結構可以被區分：
表示 ≠ 結構
因此，在模型中使用時間不能直接證明生成結構本身以時間為底層條件。
其次：
Sᵢ → Sᵢ₊₁
表明生成位置可以由生成關係形成，而不必先插入時間。生成位置形成後：
Δ(Sᵢ,Sᵢ₊₁)
生成位置差異即可成立。
差異不需要先由時間建立。接著：
Sⱼ = Sᵢ
與：
Sⱼ ≠ Sᵢ
可以分別在結構與生成位置判定上共同成立。
結構可以重現，生成位置不回返。
再者：
Cᵢ → ∅
不能推出整個生成結構停止。
指定結構中止 ≠ 生成結構中止
週期也不等於生成位置返回。
共同生成位置：
Sᵢ → G ← Sⱼ
可以在沒有時間底層的情況下成立。
而：
Sᵢ → G → Sₖ
表明目標可以承接為起點。
目標 ≠ 終止條件
G 放回整體生成鏈後，可以同時成立：
G = S₀ 結構同型
G ≠ S₀ 生成位置不同
Δ(G,S₀) 生成位置差異
這些關係可以由：
G ≃ S₀
進行高階總和表示，而不把各判定合併為同一。
TRT 自己的文字與公式也只是表示，因此整個理論仍然服從：
表示 ≠ 結構
因此，在移除時間作為底層生成條件之後，生成結構並沒有失去其成立所需的核心關係。
時間不是生成結構成立的必要底層生成條件。
時間的位置是：
Δ(Sᵢ,Sⱼ) → Tᵢⱼ時間對已成立的生成差異提供表示。
生成 → 差異 → 時間表示
這條關係只判定時間的位置。對整體生成—表示關係而言，表示形成後仍可進入後續生成：
生成 → 差異 → 表示 → 生成位置 → 差異 → 表示 → ⋯
因此，生成不是表示，表示也不是生成；但表示可以進入後續生成，兩者在持續關係中互相承接而不
互相取代。
而不是：
時間 → 生成 → 差異
這就是「時間還原」。
時間還原不是取消時間，也不是否定時間在科學、物理、測量、計算與日常世界中的功能。它所重新
確定的是時間在整體生成關係中的位置。
當時間不再被預設為生成差異的底層來源，它仍然可以對已成立的生成差異進行精確測量、標記、比
較與描述。
還原時間的位置，不是取消時間的功能。
TRT 核心命題
1. 生成結構是否必須以時間作為最底層條件，是 TRT 的核心問題。
2. 結構可以經由表示形成模型，但模型不等於結構。表示使關係兩端各自成立的屬性共同包含
於同一表示狀態而不使其成為同一；這種共同成立而不互相取代形成張力。
3. 文字、圖形、符號、公式與時間表示皆屬於表示，不因此成為其所表示的生成結構。
4. TRT 的三個不可互相取代的基本生成面向為：Sᵢ → Sᵢ₊₁（位置生成）；Sⱼ = Sᵢ（結構同型）；
Cᵢ → Cᵢ₊₁ ∨ Cᵢ → ∅（延續／中止）。
5. 三個基本生成面向不是三個先後步驟，也不是三個獨立實體，而是同一生成結構中的三個基
本生成面向。
6. Sᵢ → Sᵢ₊₁ 的箭頭表示生成關係的指向，不表示物理位移、空間方向或時間流動。
7. 生成位置形成後，生成位置差異隨之自然成立：Δ(Sᵢ,Sᵢ₊₁)。差異不是由時間或表示額外製造。
8. 結構同型不能推出生成位置同一：Sⱼ = Sᵢ 與 Sⱼ ≠ Sᵢ 可以依不同判定面向同時成立。
9. 結構可以重現，但生成位置不因此返回。
10. 指定結構中止不能推出整體生成中止：Cᵢ → ∅ 與 Sᵢ → Sᵢ₊₁ 可以同時成立。
11. G 是同一生成結構中不同基本生成面向及其差異關係共同成立的生成位置：Sᵢ → G ← Sⱼ。
12. G 不是第四個基本生成面向，也不是獨立於生成結構之外的實體。13. G 可以是前一生成關係的目標並成為下一生成關係的起點：Sᵢ → G → Sₖ。
14. 目標不等於終止條件。
15. G 與 S₀ 可以同時成立 G = S₀（結構判定）、G ≠ S₀（生成位置判定）以及 Δ(G,S₀)。
16. G ≃ S₀ 是對既有多重關係的高階總和表示，不是另一個基本生成面向或生成規則。
17. 局部判定可以重新放回同一整體生成鏈，而不切斷生成底層。
18. TRT 本身的文字與公式亦屬於表示，因此 TRT 同樣受「表示 ≠ 結構」約束。
19. 文本 B 可以在結構上精確承接文本 A，但文本 B 不因此成為文本 A 本身；表示形成後可作為
生成位置進入後續生成，差異隨之自然成立。
20. 時間表示只在生成差異已成立後進入：Δ(Sᵢ,Sⱼ) → Tᵢⱼ。
21. TRT 對時間的關係位置判定為：生成 → 差異 → 時間表示；對整體生成—表示關係則為：生
成 → 差異 → 表示 → 生成位置 → 差異 → 表示 → ⋯。
22. TRT 還原的是時間在整體生成關係中的位置，而不是取消時間的功能。

TRT 一句話定義
時間還原理論（TRT）不是把時間替換成另一種時間，而是將時間從生成結構的預設底層條件還原為
對已成立生成差異的表示；生成結構由位置生成、結構同型與延續／中止三個不可互相取代的基本生
成面向描述。生成位置形成時差異自然成立；差異可以形成表示，而表示形成後又可作為生成位置進
入後續生成。共同生成位置 G 用來判定同一生成結構中不同面向與不同差異之間如何形成關係，而
所有符號、模型、時間表示及 TRT 自身文本仍只是對生成結構的表示，不因此成為結構本身。
最終核心原則
還原時間的位置，而不是取消時間。
生成結構先由自身關係成立；差異由生成位置形成；時間再對已成立差異提供表示。
表示可以精確，但表示不因此成為結構。
結構可以重現，生成位置不回返。
局部可以中止，生成仍可繼續。
不同面向可以共同成立；生成位置形成時，差異隨之自然成立。
差異可以形成表示；表示形成後又可進入後續生成，形成生成位置與差異。
模型用來表示生成結構，但模型不是生成結構本身。
時間的位置：生成 → 差異 → 時間表示
整體關係：生成 → 差異 → 表示 → 生成位置 → 差異 → 表示 → ⋯
這就是 TRT 所要還原的時間位置，以及表示重新進入後續生成的整體關係。
